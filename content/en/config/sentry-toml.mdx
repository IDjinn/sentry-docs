# Configuration Reference (`sentry.toml`)

[`config/sentry.example.toml`](https://github.com/IDjinn/sentry/blob/main/config/sentry.example.toml) is the canonical, ready-to-copy example.

## Loading and environment overlay

The file is loaded with `figment`: the TOML is the base and **any field can be overridden by an environment variable** in the format `SENTRY_<SECTION>__<KEY>` (uppercase, `__` separates nesting levels). Secrets **never** go into the committed file — env only.

| Variable | Overrides / feeds |
| --- | --- |
| `SENTRY_STORAGE__POSTGRES__URL` | `[storage.postgres] url` |
| `SENTRY_CF_TOKEN` | Cloudflare API token (CF sources/actions) |
| `SENTRY_CF_ZONE` | Cloudflare zone ID (challenge action) |
| `SENTRY_CF_ACCOUNT` | Cloudflare account ID (/64 IP Lists) |
| `SENTRY_LLM_KEY` | LLM provider API key |
| `SENTRY_ABUSEIPDB_KEY` | AbuseIPDB key (`[ip_lookup]`, report action, feeds) |
| `SENTRY_SESSION_SECRET` | HMAC key for dashboard sessions |
| `SENTRY_WEBHOOK_SECRET` | HMAC signing secret for webhooks |
| `SENTRY_EDGE_CHALLENGE_SECRET` | Edge challenge PoW secret |

## [`[core]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L106)

Core runtime: queue buffers and hot ingest path tuning. Under overload the action queue fills first — Sentry sheds **actions**, never events.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `data_dir` | string (path) | `/var/lib/sentry` | Data directory (MMDB files, models, cache). |
| `channel_buffer` | integer | `4096` | Event channel buffer between sources and the daemon. |
| `action_buffer` | integer | `4096` | Capacity of the deferred action queue (post-processing workers). |
| `action_workers` | integer | `1` | Parallel workers executing network-bound actions. `1` preserves strict action ordering. |
| `persist_buffer` | integer | `2048` | Capacity of the batched persistence queue (one multi-row INSERT per batch). |
| `dedupe_ttl_secs` | integer | `10` | Ingest dedupe window: identical (ip, method, path) events inside the window are dropped before the pipeline. |

```toml
[core]
data_dir = "/var/lib/sentry"
action_workers = 1
dedupe_ttl_secs = 10
```

## [`[overload]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L176)

Overload response: measured pressure (queue occupancy, Postgres INSERT latency) switches on tiered degradation of **telemetry**. Detection (pipeline) and containment (block table, actions) never degrade.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | bool | `true` | Master switch for pressure detection and degradation tiers. |
| `queue_pressure` | float | `0.8` | Queue occupancy (0.0–1.0) that turns pressure on. |
| `release_pressure` | float | `0.5` | Occupancy below which pressure turns off again (hysteresis). |
| `release_secs` | integer | `30` | Seconds of sustained relief before pressure clears. |
| `pg_insert_budget_ms` | integer | `250` | INSERT latency EMA (ms) that turns pressure on by itself. |
| `sample_keep` | float | `0.1` | Fraction of low-priority events (Allow < High) kept under pressure — deterministic per source IP. |
| `coalesce_benign` | bool | `true` | Collapse repeated benign requests (Allow, GET, no signals) per (ip, path). |
| `coalesce_window_secs` | integer | `60` | Benign coalescing window: only the first hit persists. |
| `coalesce_cap` | integer | `4096` | Max tracked (ip, path) buckets; the oldest is evicted beyond it. |

## [`[deployment]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L1468)

Deployment positioning: where Sentry sits relative to the application.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `mode` | string | `passive` | `passive` reads logs/mirrored traffic and acts ex-post via actions; `inline` runs the [`[edge]`](#edge) reverse proxy in front of the app and enforces verdicts before the request reaches the backend. |
| `instance_id` | string | *(hostname)* | Instance label for metrics in multi-node deployments (`sentry_instance_info` gauge). Empty = derived from the hostname. |

## [`[storage.postgres]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L274)

Persistence connection (Postgres via sqlx).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `url` | string | *(empty)* | Connection string `postgres://user:pass@host:port/db`. Prefer `SENTRY_STORAGE__POSTGRES__URL`. |
| `max_connections` | integer | `10` | Connection pool size. |
| `acquire_timeout_secs` | integer | `5` | Seconds waiting for a free pool connection before failing fast (sqlx default is 30). |
| `statement_timeout_secs` | integer | `30` | Seconds before an INSERT is cancelled and the batch dropped, keeping the persist worker from stalling. |

## [`[[source]]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L2063)

Event sources: each entry declares a plugin `type` and a plugin-specific `options` map. Implemented types: `nginx`, `syslog`, `cloudflare` and `tcp` (unknown types are skipped with a log line).

**`type = "nginx"`** — nginx access.log tail with `log_format` parsing and automatic real-client-IP resolution.

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `path` | string | `/var/log/nginx/access.log` | Log file path. |
| `format` | string | *combined* format | Same string as the nginx `log_format`. `$http_*` tokens become event headers (usable in DSL rules like `header.cf-connecting-ip`). |

```toml
[[source]]
type = "nginx"
[source.options]
path = "/var/log/nginx/access.log"
format = '$remote_addr - $remote_user [$time_local] "$request" $status $body_bytes_sent "$http_referer" "$http_user_agent"'
```

**`type = "syslog"`** — RFC 5424 receiver (RFC 3164 fallback) for firewalls and network equipment; the peer address becomes the client IP.

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `bind` | string | `0.0.0.0:5140` | Listen address (ports < 1024 need root). |
| `transport` | string | `udp` | `udp` \| `tcp` (TCP accepts newline framing and RFC 6587 octet-counting). |

**`type = "cloudflare"`** — polling of the Cloudflare Logs API (NDJSON); requires an Enterprise plan and a token with Logs:Read via env.

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `zone_id` | string | *(required)* | Cloudflare zone ID. |
| `token_env` | string | `SENTRY_CF_TOKEN` | Environment variable holding the API token. |
| `poll_secs` | integer | `30` | Interval between polls. |
| `start` | string (RFC 3339) | *(now)* | Cursor for the first poll. |
| `api_base` | string | `https://api.cloudflare.com/client/v4` | API base URL. |

**`type = "tcp"`** — passive packet capture with SYN fingerprinting (masscan/zmap/nmap). Requires the `pcap` build feature and elevated privileges (Npcap on Windows, `CAP_NET_RAW` on Linux).

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `interface` | string | *(required)* | Capture interface. |
| `ports` | string (CSV) | *(empty = all)* | Destination-port filter, e.g. `"80,443,8443"`. |
| `payload_cap` | integer | `8192` | Reassembled bytes kept per flow. |
| `flow_cap` | integer | `65536` | Max tracked flows (FIFO eviction). |
| `channel_buffer` | integer | `1024` | Queue between the capture loop and the daemon (minimum 64). |
| `syn_window_ms` | integer | `100` | Per-IP SYN coalescing window (`0` = off); a burst becomes 1 event with `TcpData.syn_count`. |

## [`[routes]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L345)

Routes your application actually serves. Requests outside the set (or with a disallowed method) raise the `UnknownRoute` signal.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `known` | array of [`[[routes.known]]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L353) | `[]` | Each entry: `path` (exact or glob `/api/*`) and `methods` (empty = any method). |

```toml
[[routes.known]]
path = "/api/users/*"
methods = ["GET", "POST", "PATCH", "DELETE"]
```

## [`[route_learner]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L1799)

Continuous route learning: background task that infers stable route shapes from recent Postgres events and hot-reloads them. Requires Postgres storage.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | bool | `false` | Enables continuous learning. |
| `interval_secs` | integer | `300` | How often a learning pass runs. |
| `window_secs` | integer | `3600` | Look-back window for events. |
| `min_hits` | integer | `10` | Minimum hits for a shape to be considered stable. |
| `min_ips` | integer | `2` | Minimum distinct IPs that hit the shape. |

## [`[rules]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L1901)

Rules engine: default packs, static inline rules, reputation feeds and presets.

### [`[[rules.pack]]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L1921)

Default rule packs.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | string | — | Pack name (list below). |
| `mode` | string | `shadow` | `shadow` (annotate/log only) \| `enforce` (act) \| `off`. |
| `params` | table | `{}` | Extra pack parameters (e.g. `countries`, `domains`), flattened as `<pack>__<param>`. |

Available packs: `vpn_proxy`, `tor`, `crawlers_bad`, `crawlers_good` (splits into `crawlers_good_verified` / `crawlers_good_unverified_ok` with bot verification enabled), `sensitive_paths` (the only one in `enforce` by default), `empty_ua`, `http_anomaly`, `rate_scan`, `country_blocklist` (`params.countries`) and `host_allowlist` (`params.domains`).

```toml
[[rules.pack]]
name = "country_blocklist"
mode  = "off"
[rules.pack.params]
countries = ["RU", "CN"]
```

### [`[[rules.custom]]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L1948)

Static inline rules (in addition to the DB-managed ones).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | string | — | Human-readable rule name. |
| `priority` | integer | `0` | Lower = evaluated first. |
| `match` | string (DSL) | — | Match expression; a parse failure aborts config load. |
| `action` | string | — | `allow` \| `block` \| `challenge` \| `rate_limit` \| `log` \| `tag`. |
| `tags` | array of string | `[]` | Free-form tags for grouping. |
| `log_level` | string | `info` | Console verbosity: `silent` \| `info` \| `warn` \| `error`. |

```toml
[[rules.custom]]
name = "allow internal monitoring"
priority = 1
match = 'ip=10.0.0.0/8'
action = "allow"
log_level = "silent"
```

### [`[[rules.feeds]]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L1969)

Reputation feeds and datasets (one-per-line lists).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | string | — | Feed name (prefix of the synthetic rule tag). |
| `url` | string | — | http/https URL (loopback/private hosts are rejected — SSRF guard). |
| `kind` | string | `ip` | [`ip`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L2007) \| `user_agent` \| `path` \| `ja3` — one-per-line lists compile into a synthetic rule. |
| `refresh_hours` | integer | `24` | Refresh interval in hours. |
| `tier` | string | `malicious` | `unknown` \| `clean` \| `suspicious` \| `malicious` \| `datacenter` \| `vpn` \| `tor` \| `authorized` \| `promiscuous` (only for `kind = "ip"`). |
| `action` | string | *(empty)* | For `ip`: empty = enrichment only; for `user_agent`/`path`: empty = `log`. Values: `block` \| `challenge` \| `rate_limit` \| … |
| `enabled` | bool | `true` | Pause the feed without removing it. |
| `headers_env` | table | `{}` | Header → env var map for authenticated feeds (e.g. `Key = "SENTRY_ABUSEIPDB_KEY"`). |

```toml
[[rules.feeds]]
name = "spamhaus_drop"
url  = "https://www.spamhaus.org/drop/drop.txt"
tier = "malicious"
refresh_hours = 24
action = "block"
```

DB-backed datasets (the Postgres equivalent of the `user_agent`/`path`/`ja3` feeds) have no TOML entry — manage them via `sentry datasets import | list | enable | disable | delete | fetch`.

### `feed_presets`

Built-in feed presets, expanded into `feeds` at load time.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `feed_presets` | array of string | `[]` | Valid names: `tor_exit`, `firehol_level1`, `proxy_list`, `open_source_vpn_ips`, `anti_vpn`. Preset feeds **block** by default; a user-defined feed with the same name wins. |

## [`[scorer]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L363)

Signal weights and repetition bonus.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `weights` | table `name → integer` | `{}` | Overrides a signal's weight by snake_case key (e.g. `sql_injection = 35`, `random_scan = 25`). |
| `repetition_bonus` | bool | `true` | Score bonus for repeated signals in the sliding window. |
| `repetition_window_secs` | integer | `60` | Repetition tracking window duration. |

## [`[policy]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L395)

Verdict policy: maps risk level → verdict. Ordered overrides via [`[[policy.override]]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L431): the first matching DSL expression forces the verdict.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `info` | string | `allow` | Verdict for Info events. |
| `low` | string | `allow` | Verdict for Low events. |
| `medium` | string | `rate_limit` | Verdict for Medium events. |
| `high` | string | `challenge` | Verdict for High events. |
| `critical` | string | `block` | Verdict for Critical events. |
| `override` | array | `[]` | Each entry: `match` (DSL) and `verdict` (`allow` \| `rate_limit` \| `challenge` \| `block` \| `quarantine`). |

```toml
[[policy.override]]
match = 'path ^/wp-admin$ AND NOT ip=10.0.0.0/8'
verdict = "block"
```

## [`[escalation]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L458)

Repeat-offender escalation: every event with a non-Allow verdict records 1 strike for the client IP. Strikes only ever raise the verdict, never lower it, and the window should outlive the edge action TTL (returning offenders re-block on their first violating event).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | bool | `true` | Enables strike-based escalation. |
| `window_secs` | integer | `604800` | Strikes expire N seconds after the last violation (7 days, outliving the typical 24h edge TTL). |
| `challenge_at` | integer | `3` | Strikes to escalate to at least `challenge`. |
| `block_at` | integer | `5` | Strikes to escalate to `block`. |
| `persist` | bool | `true` | Mirrors strikes to the `ip_state` table (Postgres) and pre-warms the tracker on startup. |

## [`[scan]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L507)

Behavioral sweep detection: per-IP sliding window counting 4xx responses — distinct 4xx paths → `RandomScan` signal; total 4xx → `ScanBehavior`.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | bool | `true` | Enables the scan trackers. |
| `window_secs` | integer | `60` | Sliding window duration. |
| `distinct_paths` | integer | `8` | Distinct 4xx paths per IP that trigger `RandomScan`. |
| `not_found` | integer | `10` | Total 4xx responses per IP that trigger `ScanBehavior`. |

## [`[behavior]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L1136)

Behavioral auth/directory attack detection over a per-IP sliding window.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | bool | `true` | Enables the behavior trackers. |
| `window_secs` | integer | `300` | Per-IP sliding window. |
| `auth_failures` | integer | `10` | 401/403 failures on login routes that trigger `AuthBruteForce`. |
| `distinct_uas` | integer | `3` | Distinct User-Agents failing auth that trigger `CredentialStuffing`. |
| `wordlist_hits` | integer | `5` | 404s on wordlist paths that trigger `DirectoryBruteForce` (good crawlers are exempt). |
| `suspicious_success_min_failures` | integer | `3` | Auth failures that must precede a 2xx on a login route to fire `SuspiciousLoginSuccess` (`0` disables). |
| `login_patterns` | array of string | `[]` | Substrings identifying authentication routes (empty = built-in list). |
| `wordlist_paths` | array of string | `[]` | Well-known probe paths (empty = built-in wordlist). |

## [`[correlation]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L548)

Cross-IP scan→attack correlation ("shot calling" between nodes watching the same surface): an attack from IP B correlates with a scan from a *different* IP in the same /24 (IPv4), /64 (IPv6) or ASN observed within the window → `ScanAttackCorrelation` signal on B.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | bool | `true` | Enables the correlation tracker. |
| `window_secs` | integer | `900` | Maximum scan age for correlation (15 minutes). |

Rate-limit backend for DSL rate conditions (`RuleMatch::Rate`).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `backend` | string | `memory` | `memory` (in-process sliding window, single-node) \| `redis` (multi-node; requires the `rate-redis` build feature). |
| `redis_url` | string | `redis://127.0.0.1/` | Redis URL (used only with `backend = "redis"`). |

## [`[real_ip]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L626)

Real client IP resolution, trusted proxies and never-ban/never-allow sets.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `trusted_proxies` | array of string | `[]` | CIDRs/IPs of peers allowed to set client-IP headers (`CF-Connecting-IP`, `True-Client-IP`, `X-Real-IP`, XFF). Headers from other peers are ignored (anti-spoof). |
| `cloudflare` | bool | `true` | Includes the bundled Cloudflare ranges (refreshed daily from cloudflare.com/ips). |
| `trusted_ips` | array of string | `[]` | Clients never banned/blocked/reported (admins, uptime probes) — pipeline short-circuits to `Allow`. |
| `trusted_lists` | array of string | `[]` | Built-in presets approved by name (e.g. `paypal`, `stripe`, `googlebot`, `bingbot`) — join the never-ban set. |
| `whitelist` | array of string | `[]` | Allow everything, never ban — merged into the same never-ban set. |
| `blacklist` | array of string | `[]` | Deny immediately — the pipeline short-circuits to `Block` before any detector runs. |
| `shadow` | array of string | `[]` | Traffic fully processed, but the verdict is capped (`Block`/`Quarantine` downgrade to `Challenge`) — never banned. |
| `refresh_secs` | integer | `86400` | Cloudflare ranges refresh interval (`0` disables; bundled constants stay in effect). |

## [`[ip_lookup]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L696)

On-demand external reputation: gray-band IPs (elevated local score without a verdict, or carrying a listed signal) are queried at the provider and the returned confidence re-enters the pipeline (it can only raise the verdict). Consumes API quota — off by default.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | bool | `false` | Enables the lookup fork. |
| `provider` | string | `abuseipdb` | Reputation provider. |
| `key_env` | string | `SENTRY_ABUSEIPDB_KEY` | Environment variable holding the API key. |
| `trigger_above` | integer | `25` | Minimum local risk score (0–100) to trigger a lookup (verdict not yet Block). |
| `on_signals` | array of string | `[]` | Additional trigger: signal kinds (snake_case) that fire a lookup. Empty = score band only. |
| `cache_ttl_secs` | integer | `86400` | Per-IP result cache TTL. |
| `max_per_hour` | integer | `500` | Quota guard: max lookups per rolling hour. |
| `timeout_secs` | integer | `10` | Per-request timeout. |

## [`[bot_verification]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L580)

Forward-confirmed rDNS bot verification: UAs claiming to be verifiable crawlers (Googlebot, bingbot, Slurp, Baiduspider, YandexBot) are validated via PTR on the engine's domains plus forward-resolution back to the IP. Verified bots bypass the edge challenge; spoofed claims raise the `SpoofedBot` signal. DNS runs off the hot path. Inspect with `sentry bots check <ip> --ua "Googlebot/2.1"`.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | bool | `false` | Enables verification (requires DNS resolution). |
| `cache_ttl_secs` | integer | `3600` | Verified result TTL, per IP. |
| `failed_ttl_secs` | integer | `600` | Spoofed result TTL (short, so bots recover quickly from DNS outages). |
| `timeout_ms` | integer | `2000` | Timeout for one PTR+A round. |
| `batch_size` | integer | `16` | Max claims verified per background drain cycle. |

## [`[ai]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L1207)

Local classic anomaly model (ONNX) running as an async pipeline fork; the re-score can only raise. Requires the `onnx` build feature. Training: `sentry model export [--synthetic]` + `tools/train_model.py`.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | bool | `false` | Enables the model stage. |
| `model_path` | string (path) | `models/anomaly_v1.onnx` | ONNX model file. |
| `threshold` | float | `0.7` | Anomaly probability that emits the `AnomalousPayload` signal (0.0–1.0). |
| `signal_weight` | integer | `25` | Weight of the emitted signal (also overridable via `[scorer.weights]`). |
| `mode` | string | `fork` | `fork` (async) \| `inline` (blocks before actions) \| `shadow` (log only). |
| `trigger` | string | `above_score` | `always` \| `above_score` \| `quarantine_only`. |

## [`[edge]`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/config.rs#L1515)

Inline edge (required with `[deployment] mode = "inline"`). Chain: client → sentry-edge → backend. | `challenge_backend` | string | `sentry` | Who executes Challenge verdicts: `sentry` (built-in PoW) \| `cloudflare` (becomes a CF rule via the API; requires an action with `provider = "cloudflare"`). |

| `tls_handshake_events` | bool | `true` | Emits one `TlsHandshake` event per handshake (SNI + JA3 + JA4); mismatches are always emitted. |
| `tcp_listen` / `tcp_upstream` | string | *(empty)* | Inline TCP listener for non-HTTP services (e.g. `0.0.0.0:2222` → `127.0.0.1:22`); verdict on connect. |

| `upstream_connect_timeout_secs` | integer | `5` | Connect timeout for the edge → upstream hop. |
| `upstream_pool_idle` | integer | `32` | Idle keepalive connections pooled per upstream host. |

## Validation and secrets

```bash
sentry config validate   # validates schema, DSL rules and protocol schemas
sentry config show       # prints the resolved config (overlay applied)
```

`sentry config validate` compiles custom rules (the DSL is parsed at load), compiles protocol schemas when `[protocol] enabled`, **rejects** `[posture] mode = "enforce"` (still roadmap), warns about unknown ids in `[posture] checks`, and prints the edge topology/performance advisories (double TLS, off-loopback http upstream, inert compression outside inline).

Security rules:

- Secrets (Cloudflare/LLM/DB tokens, API keys, session secrets) **never** in committed config — via env (`SENTRY_*`).
- `sentry.example.toml` has placeholders, not real values.
- The `sensitive_paths` pack blocks `.env`, `.git/`, `.ssh/`, etc. by default — when exposing an allowlisted route, justify it in the PR.
