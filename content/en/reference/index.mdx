# Reference

This section is the **API reference** for the public Sentry crates. It documents the surface a plugin author (the `Source`/`Action`/provider traits) or an operator (config types, storage repos, the edge runtime) touches — not every private function.

## Conventions

- Every documented item (struct, enum, trait, fn, module) carries a **link to its source** on GitHub, with a line anchor — e.g. [`Event`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L198). The code is the source of truth; these pages give signatures and semantics.
- Code blocks show the **signature only** (with the `///` doc-comment when it summarizes the contract), never the body.
- Organization is **crate → module → item**: `##` for modules, `###` for items. Field/variant/method lists use tables where that reads better than prose.
- Documented signal weights and thresholds are the **compiled-in defaults**; almost all of them can be overridden by config (`[scorer.weights]`, tracker windows, etc.). When an override applies, the config value wins.

## Crate map

The workspace has 19 crates. Every plugin crate depends only on `sentry-core` (contracts), never on another plugin; heavyweight deps sit behind optional features.

## Stability

- **MSRV 1.80** (Rust 2021), pinned in the workspace [`Cargo.toml`](https://github.com/IDjinn/sentry/blob/main/Cargo.toml) — the floor exists because of `std::sync::LazyLock`.
- **No `unsafe`**: every lib crate declares `#![forbid(unsafe_code)]` (e.g. [`sentry-core`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/lib.rs#L11), [`sentry-protocol`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-protocol/src/lib.rs#L48)).
- The golden rule of the data model: the `Event` is modular via [`ProtocolData`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L396) — no consumer assumes an event is HTTP. New protocols join as enum variants, never as loose fields.
- Heavyweight features are **optional and off by default**: `onnx` (local inference), `edge-tls` (HTTPS front), `edge-zstd`, `pcap`, `rate-redis`, `service`. The surface documented here exists independently of them unless noted.
