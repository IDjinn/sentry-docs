# API — `sentry-core`

[`sentry-core`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/lib.rs#L1) is the contracts crate: domain model, plugin traits, rules engine, heuristics and trackers. It is **pure** — no I/O, no HTTP, no DB — and declares `#![forbid(unsafe_code)]`. Every plugin crate depends only on it.

## Domain model — module `event`

### Event

[`Event`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L198) is the normalized, protocol-agnostic event that flows through the whole pipeline. Common fields live on the struct; protocol specifics live in `protocol: ProtocolData`.

```rust
pub struct Event {
    pub id: Uuid,
    pub timestamp: DateTime<Utc>,
    pub source: SourceKind,
    pub transport: Transport,
    pub client_ip: IpAddr,
    pub geo: Option<GeoInfo>,
    pub asn: Option<u32>,
    /* ... bytes, duration, reputation, bot ... */
    pub protocol: ProtocolData,
}
```

Accessors that pattern-match the payload — heuristics and rules use them to opt into protocol-specific logic without assuming every event is HTTP:

| Method | Returns |
| --- | --- |
| [`http()`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L274) / [`http_mut()`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L282) | `Option<&HttpData>` |
| [`tcp()`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L290) | `Option<&TcpData>` |
| [`tls()`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L298) | `Option<&TlsData>` |
| [`syslog()`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L305) | `Option<&SyslogData>` |
| [`is_http()`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L314) / [`protocol_kind()`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L319) | `bool` / [`ProtocolKind`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L85) |

[`Event::new`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L248) creates with a fresh id/timestamp; [`Event::canonical_ip`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L243) normalizes IPv4-mapped IPv6 (`::ffff:a.b.c.d`) to plain IPv4 — the same client maps to a single key across blocks, storage and the CLI.

### ProtocolData

[`ProtocolData`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L396) is the enum that keeps the `Event` extensible. Adding a protocol = a new variant + a helper on `impl Event` + updating `protocol_kind()`.

| Variant | Payload |
| --- | --- |
| `Http(HttpData)` | HTTP/1.x or HTTP/2 request |
| `Tcp(TcpData)` | Non-HTTP TCP stream (capture, edge-tcp) |
| `Udp(UdpData)` | UDP datagram ([`UdpData`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L541), decodes DNS when recognized) |
| `TlsHandshake(TlsData)` | ClientHello telemetry (SNI/JA3/JA4) |
| `Syslog(SyslogData)` | RFC 5424/3164 message |
| `Raw(RawData)` | Fallback ([`RawData`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L568)) |

### HttpData, UploadInfo and the smaller enums

[`HttpData`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L413) carries method/scheme/host/path/query/status/user_agent/headers/cookies/body/uploads. `body` is only populated by inline sources and falls back to the capture cap after the pipeline runs. [`UploadInfo`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L450) is upload metadata (F10) — content never persists; [`UploadKind`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L466) classifies by magic bytes (`Text`/`Image`/`Archive`/`Executable`/`Pdf`/`Unknown`).

Other types in the module: [`TcpData`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L484) (flags, reassembled payload, SYN `fingerprint`, burst `syn_count`), [`TcpFlags`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L507), [`TcpStage`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L525), [`TlsData`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L550) (sni/ja3/ja4/cipher/version/alpn), [`SyslogData`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L577), [`SourceKind`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L19), [`Transport`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L61), [`HttpMethod`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L103), [`GeoInfo`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L168) and [`ReputationInfo`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L184). [`RawEvent`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L338) is what the `Source` trait emits, before enrichment; [`into_event`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L369) promotes it to `Event`.

### Verdict, RiskLevel, AnalysisResult and Decision

[`Verdict`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/analysis.rs#L231) is the recommended action: `Allow` / `RateLimit` / `Challenge` / `Block` / `Quarantine`. [`RiskLevel`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/analysis.rs#L18) buckets the 0–100 score into five fixed levels ([`from_score`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/analysis.rs#L37): Info 0–9, Low 10–29, Medium 30–49, High 50–74, Critical 75+).

[`AnalysisResult`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/analysis.rs#L247) is the detection (score + signals + pre-policy verdict); [`Decision`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/analysis.rs#L329) is the final response after policy, with `override_reason` and an optional `log_level`. [`RuleLogLevel`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/analysis.rs#L290) controls console verbosity for short-circuited events (`silent|info|warn|error`).

## Plugin traits

### Source

Implemented by every data origin ([`source.rs`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/source.rs#L26)):

```rust
#[async_trait]
pub trait Source: Send + Sync {
    fn name(&self) -> &'static str;
    async fn stream(&self) -> Result<mpsc::Receiver<RawEvent>>;
    async fn shutdown(&self) -> Result<()> { Ok(()) }
}
```

The origin is opened inside `stream`, which returns the **receiver** end of a bounded channel; dropping the sender signals end-of-stream. Module helpers: [`event_channel`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/source.rs#L49) (standard sizing) and [`send_or_log`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/source.rs#L64) (push with a per-source log throttle when the channel fills).

### Action, ActionContext and ActionDispatch

Implemented by every response ([`action.rs`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/action.rs#L74)):

```rust
#[async_trait]
pub trait Action: Send + Sync {
    fn name(&self) -> &'static str;
    async fn execute(&self, evt: &Event, decision: &Decision) -> Result<()>;
    async fn execute_with_context(&self, evt: &Event, decision: &Decision, ctx: &ActionContext) -> Result<()>;
    fn applies_to(&self, decision: &Decision) -> bool;
    fn dispatch(&self) -> ActionDispatch;
}
```

Implementations must be idempotent (replay after a restart is a no-op, not an error). [`ActionContext`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/action.rs#L60) carries the `incident_id` for bidirectional alerting (F4.5). [`ActionDispatch`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/action.rs#L24) decides where the action runs: `Inline` (local containment, hot path) or `Deferred` (default; network I/O goes to post-processing workers).

### ChallengeProvider

The provider-agnostic edge abstraction ([`challenge.rs`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/challenge.rs#L95)) — mirrors the `LlmProvider` pattern:

```rust
#[async_trait]
pub trait ChallengeProvider: Send + Sync {
    fn name(&self) -> &'static str;
    async fn apply(&self, ip: IpAddr, verdict: Verdict, opts: &EdgeOptions) -> Result<()>;
}
```

[`ChallengeAction`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/challenge.rs#L114) is the single `Action` edge providers need: it filters the `Block`/`Challenge`/`RateLimit` verdicts (skips `Allow`/`Quarantine`) and delegates to the provider. [`EdgeMode`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/challenge.rs#L31) is the flavor (`block`/`js_challenge`/`managed_challenge`/`rate_limit`) and [`EdgeOptions`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/challenge.rs#L71) carries TTL + preferred mode. A new edge provider (AWS WAF, Fastly…) = implement the trait + one arm in `daemon::build_challenge_action`.

## AI providers (crate `sentry-ai`)

### LlmProvider

The LLM classification contract ([`llm.rs`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-ai/src/llm.rs#L95)):

```rust
#[async_trait]
pub trait LlmProvider: Send + Sync {
    fn name(&self) -> &'static str;
    fn model_id(&self) -> &str;
    async fn classify(&self, req: ClassifyRequest) -> anyhow::Result<ClassifyResponse>;

```

Bundled adapters: [`OpenRouterProvider`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-ai/src/llm/openrouter.rs#L35) (default, `SENTRY_LLM_KEY`), [`OllamaProvider`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-ai/src/llm/ollama.rs#L34) (local, keyless) and [`MockLlmProvider`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-ai/src/llm/mock.rs#L13). [`ClassifyResponse`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-ai/src/llm.rs#L56) carries verdict, score, confidence and token usage.

### IpLookupProvider

External per-IP reputation lookup (F7.5, [`lookup.rs`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-ai/src/lookup.rs#L30)):

```rust
#[async_trait]
pub trait IpLookupProvider: Send + Sync {
    fn name(&self) -> &'static str;
    async fn check(&self, ip: IpAddr) -> Result<IpLookupResult, String>;
}
```

[`AbuseIpDbLookup`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-ai/src/lookup.rs#L40) implements `GET /api/v2/check`; the returned `score` scales the `ExternalReputation` signal weight. The daemon's async fork only queries the gray band (score above the trigger, verdict ≠ Block), with caching and quota.

## Rules engine — module `rules`

### Rule, RuleSet and SharedRuleSet

```rust
pub struct Rule {
    pub id: RuleId,
    pub priority: i32,      // lower = evaluated first
    pub enabled: bool,
    pub match_: RuleMatch,
    pub action: RuleAction,
    pub ttl: Option<Duration>,
    pub source: RuleSource,
    /* tags, log_level, created_at */
}
```

[`Rule`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/rules.rs#L155) is evaluated on the fast path, before heuristics and AI. [`RuleSet`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/rules.rs#L188) indexes rules by IP/ASN/country for fast lookup; [`SharedRuleSet`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/rules.rs#L198) is the `Arc<RwLock<>>` handle that hot-reload swaps ([`shared()`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/rules.rs#L201)).

### RuleAction and RuleSource

[`RuleAction`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/rules.rs#L126): `Allow` (full bypass) > `Block`/`Challenge`/`RateLimit` (short-circuit) > `Log`/`Tag` (annotate and continue). [`RuleSource`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/rules.rs#L108) records the origin (`config`/`db`/`cloudflare_sync`/`feed`/`auto_learned`/`default_pack`).

### RuleMatch

[`RuleMatch`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/rules.rs#L358) is the declarative condition, composable with `All`/`Any`/`Not`: `Ip(cidr)`, `Asn`, `Country`, `Path{op, pattern}`, `Method`, `Header{name, op}`, `UserAgent`, `Query`, `Body`, `UploadFilename`, `Protocol`, `TlsFingerprint{ja3, ja4}`, `TlsSni`, `Ja3In(set)`, `Reputation(tier)`, `BotVerified`, `Status`, `Rate{count, per_secs, scope}`, `Time`.

### DSL

The `match = "..."` text in TOML is compiled by [`dsl::parse`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/rules/dsl.rs#L36) (recursive descent, `AND`/`OR`/`NOT`/parentheses) into a `RuleMatch`. Typos fail at load time, not at runtime. [`rules_from_config`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/rules.rs#L210) compiles each `[[rules.custom]]` independently — one invalid expression skips just that rule. [`ReputationTier`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/rules.rs#L488) (`malicious`/`tor`/`vpn_proxy`/`promiscuous`/`authorized`) feeds `Reputation(tier)`.

## Policy — module `policy`

### VerdictPolicy

[`VerdictPolicy`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/policy.rs#L17) is the configurable detection→action mapping. The default preserves the historical mapping (Info/Low→Allow, Medium→RateLimit, High→Challenge, Critical→Block); each level is remappable in TOML and `[[policy.override]]` forces a verdict via DSL — the first matching override wins and populates `Decision.override_reason`.

```rust
pub fn from_config(cfg: &PolicyConfig) -> Result<Self>;
pub fn decide(&self, level: RiskLevel, evt: &Event) -> (Verdict, Option<String>);
```

## Pipeline — module `pipeline`

### Pipeline

[`Pipeline`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/pipeline.rs#L304) orchestrates rules → heuristics → routes → scorer → policy → escalation. Built through chained builders:

| Method | Arms |
| --- | --- |
| [`with_config`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/pipeline.rs#L362) | shared ruleset + routes + scorer + policy |
| [`configure_uploads`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/pipeline.rs#L398) | body/upload inspection (F10) |
| [`with_trust`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/pipeline.rs#L414) | never-ban/blacklist/shadow (F7.2) |
| [`with_rate_limiter`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/pipeline.rs#L420) | backend for `Rate` conditions |
| [`with_offender`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/pipeline.rs#L426) | repeat-offender escalation |

## Heuristics — module `heuristics`

### Heuristic and HeuristicEngine

```rust
pub trait Heuristic: Send + Sync {
    fn name(&self) -> &'static str;
    fn gate_bit(&self) -> Option<u8> { None }
    fn analyze(&self, evt: &Event, text: &DecodedHttp<'_>) -> Vec<Signal>;
}
```

[`Heuristic`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/heuristics.rs#L22) is a regex detector; [`HeuristicEngine`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/heuristics.rs#L355) runs them all ([`analyze`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/heuristics.rs#L410)). Performance (F5): an Aho-Corasick automaton of trigger literals ([`gate`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/heuristics.rs#L99)) gates the regexes — clean traffic costs one SIMD pass. Bundled families: `SqlInjection`, `Xss`, `PathTraversal`, `Lfi`, `Log4Shell`, `CmdInjection`, `SensitivePath`, `BadCrawler`, `EmptyUserAgent`, `TcpScanner` + the upload ones (F10, with `gate_bit() = None` because they operate on body content, not path text).

### DecodedHttp

[`DecodedHttp`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/heuristics.rs#L44) carries the **URL-decoded** path and query (`%27`→`'`, `+`/`%20`→space) computed once per event, plus parsed multipart/urlencoded content. When writing a new heuristic, analyze `text.path`/`text.query` — never the raw `http.path`, or encoded payloads bypass you. (The decode happens in the internal [`http_text`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/heuristics.rs#L506) helper.)

### reload_dataset_lists

```rust
pub fn reload_dataset_lists(user_agents: &[String], paths: &[String]);
```

[`reload_dataset_lists`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/heuristics.rs#L296) merges literals from DB-backed datasets (`user_agent`/`path`) into the prefilter gates via `ArcSwap` — hot-reload without a restart (F7.7).
