# Referência

Esta seção é a **referência de API** das crates públicas do Sentry. Ela documenta a superfície que um autor de plugin (traits `Source`/`Action`/providers) ou um operador (types de config, repos de storage, runtime da edge) toca — não cada função privada.

## Convenções

- Cada item documentado (struct, enum, trait, fn, módulo) leva um **link para o fonte** no GitHub, com âncora de linha — ex.: [`Event`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L198). O código é a verdade; aqui vão assinaturas e semântica.
- Blocos de código mostram **apenas a assinatura** (com o doc-comment `///` quando ele resume o contrato), nunca o corpo.
- A organização é **crate → módulo → item**: `##` para módulos, `###` para itens. Listas de campos/variantes/métodos usam tabelas quando ficam mais legíveis que prosa.
- Pesos de sinal e thresholds documentados são os **defaults compilados**; quase todos podem ser sobrescritos por config (`[scorer.weights]`, janelas de trackers etc.). Quando houver override, o valor da config vence.

## Estabilidade

- **MSRV 1.80** (Rust 2021), fixado no [`Cargo.toml`](https://github.com/IDjinn/sentry/blob/main/Cargo.toml) do workspace — o piso existe por causa de `std::sync::LazyLock`.
- **Sem `unsafe`**: todas as lib crates declaram `#![forbid(unsafe_code)]` (ex.: [`sentry-core`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/lib.rs#L11), [`sentry-protocol`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-protocol/src/lib.rs#L48)).
- A regra de ouro do modelo de dados: o `Event` é modular via [`ProtocolData`](https://github.com/IDjinn/sentry/blob/main/crates/sentry-core/src/event.rs#L396) — nenhum consumidor assume que um evento é HTTP. Novos protocolos entram como variantes do enum, nunca como campos soltos.
- Features pesadas ficam **opcionais e desligadas por default**: `onnx` (inferência local), `edge-tls` (frente HTTPS), `edge-zstd`, `pcap`, `rate-redis`, `service`. A superfície documentada aqui existe independente delas, salvo indicação.
